# Демо-проект по копмьютерной безопасности

## Безопасный файлообменник с шифрованием, авторизацией, работой через docker с любой машины. 

## Технологии и используемые библиотеки:
- fastAPI;
- Docker;
- Fernet;
- pathlib;
- dotenv;
- uuid.

## Инструкция по запуску
1) git clone ...
2) cp .env.example .env
3) docker compose up -d


## Демонстрация API

Перейдите на http://<ip машины/localhost>:port/docs

Здесь вы сможете протестировать весь бэкенд проекта, авторизацию пользователей, их доступ к различным файлам, загрузку и выгрузку изображений и текстовых документов. 

## Проект включает в себя:
1) Авторизацию
2) Получение текущей сессии
3) Отключение от текущей сессии
4) Отправку и вывод комментариев (тест)
5) Получение информации о конкретном файле
6) Удаление файла
7) Получение информации о всех своих файлах
8) Получение информации о всех файлах (для админа)
9) Загрузка файла на сервер
10) Скачка файла с сервера
